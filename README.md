# USA from LA

Request-a-size landing page for the family California → Romania pilot.

- Public brand: USA from LA
- Legal seller: Niculae Bolos, Petroșani
- No checkout, no Laguna Electric Inc.
- Form opens WhatsApp with a prefilled request

## Before sharing

1. In `config.js`, set `whatsapp` to Niculae’s mobile (digits only, start with 40 — example `40712345678`).
2. GitHub → Settings → Pages → Deploy from branch `main`.
3. Live URL after Pages is on: https://lagunavibes.github.io/usa-from-la/
